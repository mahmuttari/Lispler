# Calqora — ko-KR

- **Uygulama adı:** Calqora 공학용 계산기

## Kısa açıklama

그래프, 복소수, 행렬, 단위 변환, 상수까지 담은 공학용 계산기.

## Uzun açıklama

Calqora는 학교, 직장, 현장에서 필요한 계산을 하나로 모은 공학용 계산기입니다. 종이에 쓰듯이 식을 입력하세요. 루트 기호의 가로선이 안의 식 전체를 덮고, 입력하는 동안 결과가 바로 나타납니다.

🧮 계산
• 삼각함수와 쌍곡선함수, 로그, 거듭제곱과 거듭제곱근. 각도 단위 DEG, RAD, GRAD.
• 팩토리얼, 조합, 순열, 최대공약수, 최소공배수, 나머지, 반올림, 감마 함수.
• 합(Σ), 곱, 수치 미분, 정적분, 방정식 풀이.
• 결과를 분수, 대분수, 도·분·초로 보기.
• Norm, Fix, Sci, Eng 표시 형식과 자릿수 선택. 소수점은 마침표 또는 쉼표.
• Ans, 메모리 M+ / M− / MR, 변수 A, B, C, D, X, Y. 최근 100개 계산 기록.

📈 그래프
• 함수 4개까지 한 번에 그리기. 한 손가락으로 이동, 두 손가락으로 확대·축소.
• 곡선을 따라가며 각 점의 값 읽기.
• 보이는 범위에서 근, 최솟값·최댓값, 두 곡선의 교점 찾기.

ℂ 복소수
• 복소수 모드에서는 √(−4) = 2i. a+bi 또는 r∠θ 표시.
• re, im, conj, arg와 복소수의 모든 기본 함수.

▦ 행렬
• 행렬 A, B, C(최대 5×5). 칸에 1/3이나 √(2) 같은 식도 입력 가능.
• 덧셈, 뺄셈, 곱셈, 역행렬, 전치, 거듭제곱, 행렬식, 계수, 대각합, 기약 행 사다리꼴(rref), 고윳값, X⁻¹·Y로 연립일차방정식 풀이.

⇄ 단위와 상수
• 15개 분류, 140개 단위: 길이, 넓이, 부피, 질량, 밀도, 시간, 속도, 힘, 압력·응력, 에너지, 일률, 온도, 각도, 주파수, 데이터.
• 값 하나를 입력하면 분류 안의 모든 단위로 바로 보여 줍니다.
• 수학, 물리, 화학, 천문학, 공학 상수 46개: 빛의 속도, 플랑크 상수, 아보가드로 수, 표준 중력 가속도, 물의 단위 중량 등. 한 번 탭으로 계산에 넣기.

🌍 11개 언어
• Türkçe, English, Deutsch, Français, Español, Italiano, Português, Русский, 日本語, 한국어, العربية. 라이트·다크 테마, 가로 화면에서는 넓은 키패드.

🔒 개인정보
• 계정도, 자체 서버도 없습니다. 식, 기록, 설정은 휴대전화에만 저장되며 계산에 인터넷 연결이 필요하지 않습니다.

ℹ️ 알아 두세요
• 계산은 배정밀도 부동소수점(유효숫자 약 15자리)으로 합니다. 수치 미분, 적분, 방정식 풀이는 근삿값을 줍니다. 시험이나 공식 업무에서는 결과를 다시 확인하세요.

이 앱에는 광고가 있습니다. 화면 하단에 배너 광고가 표시되고, 전체 화면 광고는 그래프·행렬·단위 화면을 나가거나 설정을 닫을 때만 최소 4분 간격으로 표시되며 입력 중에는 나타나지 않습니다. 선택 사항인 광고 없는 구독을 이용하면 모든 광고가 사라지며 언제든지 해지할 수 있습니다.
