▶ HTML ÇALIŞTIR
• HTML, CSS ve JavaScript yazın, .html olarak kaydedin ve yeşil "Çalıştır" düğmesine basın.
• Sayfanız tam ekran açılır; console.log çıktıları ve hatalar satır numarasıyla Konsol'da görünür.
• Hazır HTML şablonu ile saniyeler içinde başlayın.
• Aynı uygulamadaki stil.css ve kod.js dosyalarınızı bağlayabilirsiniz.

📝 TANIDIK MENÜLER
• Dosya: Yeni, Aç, Kaydet, Farklı Kaydet, Paylaş
• Düzen: Geri Al, Yinele, Kes, Kopyala, Yapıştır, Bul, Değiştir, Satıra Git, Saat/Tarih
• Biçim: Sözcük Kaydırma, Yazı Tipi
• Görünüm: Yakınlaştır, Durum Çubuğu, Koyu Tema

📱 TELEFON İÇİN TASARLANDI
• Sembol çubuğu: < > / = " { } gibi işaretler klavyenin hemen üstünde.
• </> düğmesi son açtığınız HTML etiketini otomatik kapatır.
• Telefonunuzdaki dosyaları açın, düzenleyin, aynı dosyaya geri kaydedin.
• Kaydetmeyi unutsanız bile yazdıklarınız kaybolmaz.
